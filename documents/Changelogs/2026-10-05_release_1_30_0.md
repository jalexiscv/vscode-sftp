# Release 1.30.0: actualización desde las releases de GitHub

**Fecha:** 2026-10-05
**Área:** release

## Descripción

Release de funcionalidad. Responde a la pregunta del usuario de si la
extensión podía actualizarse sola cuando se publicara una versión nueva en
GitHub: VS Code solo actualiza por su cuenta lo que viene del Marketplace, así
que la propia extensión consulta ahora la última release, la ofrece y, a
petición del usuario, la descarga, la verifica y la instala.

Cambios incluidos:

- [Actualización desde las releases de GitHub](2026-10-05_feat_actualizacion_desde_github.md) (#69)

## Tipo de Cambio

- `Añadido`
- `Cambiado` (el workflow publica `<vsix>.sha256` junto al vsix)

  los suyos al terminar.

## Impacto

- A partir de esta versión, cada release nueva se ofrece desde la propia
  extensión (una consulta diaria a la API de GitHub) y se instala con dos
  clics y una recarga. Las releases anteriores no tienen checksum, así que el
  flujo empieza a verse con la primera release posterior a instalar esta.
- No verificado en un VS Code real: la llamada a
  `workbench.extensions.installExtension` con el `Uri` del vsix. Si fallara,
  `Release notes` abre la página de la release para instalar a mano.
- Como en toda versión nueva desde la 1.27.0, el índice de sincronización y el
  registro de actividad se descartan al activarse por primera vez.
- Formato de `sftp.json`, comandos existentes y flujos sin cambios.
